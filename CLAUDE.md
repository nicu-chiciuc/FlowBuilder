## Multi-Agent Collaboration

This codebase may have multiple AI agents working in parallel on different tasks.

### Git Commit Rules
- Make **atomic commits**: one logical change per commit
- Only commit files YOU directly modified
- Do not stage or commit unrelated changes you notice
- If you see unexpected modifications, leave them alone—another agent may be working on them
- Use clear, descriptive commit messages explaining YOUR specific change
- Commit frequently at logical boundaries rather than batching all changes

### Conflict Avoidance
- Before editing a file, check if it has uncommitted changes that aren't yours
- If working on a shared file, make minimal, focused changes
- Prefer additive changes over modifications when possible
